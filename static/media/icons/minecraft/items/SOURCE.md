Minecraft item inventory icons
==============================

Most icons in this directory are generated from the installed Minecraft client jar.

Where an exact pre-rendered item PNG is available, the icon builder prefers the
Minecraft Item Gallery enhanced image set:

- Source: https://github.com/TinyTank800/MinecraftAllImages
- Image set: `public/images-v2/1.21.1`
- License: MIT License
- Copyright: Copyright (c) 2025 TinyTank800

Items missing from that image set are rendered locally from the installed
Minecraft client assets by `scripts/build_minecraft_item_icons.py`.
